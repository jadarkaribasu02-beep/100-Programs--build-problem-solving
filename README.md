# 🚀 100 Basic Programs Roadmap

A structured roadmap of **100 beginner-friendly programs** to build strong problem-solving skills in any language (Python / Java / C++).  
Designed for absolute beginners before diving into **DSA** or **LeetCode**.

---

## 📖 How to Use
1. Pick **one language** and stick to it for all 100 programs.
2. Solve strictly **in order** (easy → moderate → challenge).
3. Struggle for **10–15 minutes** before checking solutions.
4. **Type the code yourself** — no copy-paste.
5. After solving, ask: *“Can I do it cleaner or shorter?”*
6. Wherever `n` appears, take it as **user input**.
7. Aim for **3–5 programs per day** → finish in ~1 month.

---------------------------------------------------------------------

## 🏆 Levels Overview
- **Level 1:** Warm-up (Hello World, input/output, variables)
- **Level 2:** Conditions (if/else problems)
- **Level 3:** Loops (natural numbers, sums, factorials)
- **Level 4:** Digits of a number (reverse, palindrome, digit sum)
- **Level 5:** Number classification (prime, Armstrong, perfect)
- **Level 6:** Series & Patterns (Fibonacci, Pascal’s triangle, star patterns)
- **Level 7:** Strings (palindrome, anagram, frequency count)
- **Level 8:** Arrays / Lists (search, sort, duplicates)
- **Level 9:** Challenge Round (mix of all concepts)
